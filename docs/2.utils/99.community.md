# 社区

> 来自社区的 H3 工具。

您可以使用由社区制作的外部 H3 事件工具。

本节为任何兼容 H3 版本 2 的新社区库预留位置。
<br>
<br>

> [!TIP]
> 💛 欢迎提交 PR 来列出您的库。

## `apitally`

[Apitally](https://apitally.io/h3) 是一个简单的 API 监控、分析和请求日志工具，带有 H3 的插件。请在 [这里](https://docs.apitally.io/frameworks/h3) 查看设置指南。

:read-more{to="https://github.com/apitally/apitally-js"}

## `H3ravel Framework`

[H3ravel Framework](https://h3ravel.toneflix.net) 是一个现代的、与运行时无关的 TypeScript Web 框架，构建于 H3 之上，旨在将 Laravel PHP 的优雅和开发者体验带到 JavaScript 生态系统。入门指南见[这里](https://h3ravel.toneflix.net/guide/get-started)。

:read-more{to="https://github.com/h3ravel"}

## `Intlify`

[Intlify](https://intlify.dev/) 是一个旨在提升软件国际化开发者体验的项目。该项目提供服务端框架、中间件和实用工具。关于这些内容，请见[这里](https://github.com/intlify/srvmid)

:read-more{to="https://github.com/intlify/srvmid"}

## `Clear Router`

A Laravel-style routing system for H3 and Express.js. Supports concise route definitions, middleware support, and controller binding, with full TypeScript support.

:read-more{to="https://github.com/toneflix/clear-router"}

## `unjwt`

`unjwt` 是一个基于 Web Crypto API 构建的低级 JWT 工具集合（JWS、JWE、JWK），零运行时依赖。它包含一个专用的 H3 v2 适配器，用于基于请求头和 Cookie 的会话管理，支持加密（JWE）和签名（JWS）令牌。

:read-more{to="https://github.com/sandros94/unjwt"}

## `Arkstack`

[Arkstack](https://arkstack.toneflix.net) 是一个与运行时无关的 TypeScript 后端框架，用于构建结构化、可用于生产的服务器应用，并且对 H3 提供一流支持。

:read-more{to="https://arkstack.toneflix.net/guide/getting-started"}
